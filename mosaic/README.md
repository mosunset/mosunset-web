# モザイク処理ツール

画像内の顔、名前、日付を自動検出してモザイク処理を行うツールです。**GUI版**と**CLI版**の2つのモードがあります。

## 機能

- **顔検出**: OpenCVのHaar Cascadeを使用して顔を自動検出
- **テキスト検出**: EasyOCRを使用して名前などのテキストを自動検出
  - 日本語、英語、韓国語、中国語など任意のUTF-8文字列に対応
- **日付検出**: EasyOCRを使用して日付全般（誕生日、有効期限、発行日など）を自動検出
  - 西暦・和暦・スラッシュ表記などに対応
- **GUI版**: 対話的な編集インターフェース
  - 自動検出した領域を表示・編集
  - 手動で範囲選択を追加・削除・移動・拡大縮小
  - 1枚ずつ確認してから処理
- **CLI版**: コマンドラインで一括処理
  - 自動検出して自動的に全て処理
- **ごま塩ノイズ**: モザイク処理前に検出範囲にごま塩ノイズを追加（より強力に隠蔽）
- **マージン付きモザイク**: 検出範囲の15%のマージンを追加してモザイクをかける
- **EXIF削除**: 画像のメタデータ（位置情報など）を自動削除

## インストール

```bash
# 依存関係のインストール（uvを使用）
uv sync

# または、pipを使用
pip install opencv-python easyocr pillow
```

## 使い方

### GUI版（推奨）- 対話的な編集

GUI版では、自動検出した領域を確認・編集してから処理できます。

**起動方法:**

```bash
# ディレクトリを選択ダイアログで指定
python main_gui.py

# コマンドラインでディレクトリを指定
python main_gui.py /path/to/your/images

# Windows の例
python main_gui.py C:\Users\user\Pictures
```

**操作方法:**

1. **自動検出**: 画像を開くと自動的に顔・名前・日付が検出されます
   - 「自動検出」ボタンで再検出も可能
2. **編集**:
   - 左クリック＆ドラッグ: 新しい範囲を手動で選択
   - 矩形をクリック: 既存の範囲を選択
   - 矩形をドラッグ: 範囲を移動
   - **矩形のハンドルをドラッグ: 範囲を拡大縮小**
     - 四隅のハンドル: 対角方向にリサイズ
     - 辺の中央のハンドル: その方向にリサイズ
   - 右クリック: 範囲を削除
   - リストから選択: 範囲をハイライト
3. **削除**: 「選択を削除」で個別削除、「全て削除」で一括削除
4. **保存**: 「モザイク処理して保存」で確定
5. **ナビゲーション**: 「次へ」「前へ」ボタンで画像を切り替え

**色分け:**
- 赤: 顔検出
- 青: テキスト（名前など）
- 緑: 日付
- 黄: 手動追加

**リサイズハンドル:**
- 選択中の矩形には白い四角いハンドルが表示されます
- 四隅のハンドル（4個）: 対角方向に拡大縮小
- 辺の中央のハンドル（4個）: その辺の方向に拡大縮小
- ハンドルにマウスを合わせるとカーソルの形が変わります

### CLI版 - 一括自動処理

CLI版では、自動検出した領域を全て自動的に処理します。

**方法1: カレントディレクトリを処理**

```bash
cd /path/to/your/images
python main.py
```

**方法2: 処理するディレクトリを指定**

```bash
python main.py /path/to/your/images
```

Windows の例:
```bash
python main.py C:\Users\user\Pictures
```

**方法3: 出力先も指定**

```bash
python main.py /path/to/your/images -o /path/to/output
```

**ヘルプの表示:**

```bash
python main.py --help
```

### 処理結果

処理された画像は、デフォルトでは処理対象ディレクトリ内の `_anonymized` フォルダに保存されます。`-o` オプションで出力先を変更できます。

## 設定のカスタマイズ

`main.py` の先頭にある設定パラメータを編集することで、動作をカスタマイズできます：

### 基本設定

```python
# モザイクの強さ（0.01～0.2程度、小さいほど強いモザイク）
MOSAIC_RATIO = 0.07

# 出力先フォルダ名
OUTPUT_DIRNAME = "_anonymized"

# OCR（テキスト検出）の有効/無効
USE_OCR = True

# OCR検出の信頼度閾値（0.0～1.0、値が高いほど確実なもののみ検出）
OCR_CONFIDENCE_THRESHOLD = 0.4  # デフォルト: 0.4（推奨: 0.3～0.5）

# モザイク範囲のマージン（検出範囲の何%拡大するか）
MOSAIC_MARGIN_RATIO = 0.15  # 15%のマージン

# ごま塩ノイズを追加するか
ADD_SALT_PEPPER_NOISE = True

# ごま塩ノイズの密度（0.0～1.0、値が大きいほどノイズが多い）
NOISE_AMOUNT = 0.05  # 5%のピクセルにノイズを追加
```

### テキスト検出の設定

```python
# 特定のテキストだけを検出する場合（名前など）
# 日本語、英語、韓国語、中国語など任意の言語に対応
# 空リストの場合は、指定長さの範囲内の任意の文字列を検出対象とする
TARGET_NAMES = ["山田", "太郎", "鈴木", "花子", "Smith", "asano", "yuya", "김철수", "王小明"]

# 検出対象として認識する文字列の長さ（最小・最大）
NAME_MIN_LENGTH = 2
NAME_MAX_LENGTH = 4
```

### 日付検出の設定

```python
# 日付検出を有効にするか（誕生日、有効期限、発行日など全ての日付）
DETECT_DATE = True
```

### 対象ファイル形式

```python
IMAGE_EXTS = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}
```

## 検出の仕組み

### テキスト検出（名前など）

テキスト検出は以下の基準で行われます：

1. **特定のテキストリスト**: `TARGET_NAMES` にテキストを指定した場合、そのテキストのみを検出
   - 英文字は大文字小文字を区別せず検出（`"asano"`、`"Asano"`、`"ASANO"` すべて検出）
   - 任意の言語に対応（日本語、英語、韓国語、中国語、アラビア語など）
2. **自動検出**: `TARGET_NAMES` が空の場合、以下の条件に合うテキストを検出
   - 任意のUTF-8文字列（日本語、英語、韓国語、中国語など全ての言語）
   - 指定された長さの範囲内（デフォルト: 2～4文字）
   - 少なくとも1文字は文字（Letter）を含む（記号や数字のみは除外）

**検出例:**
- 日本語: `山田`, `田中`, `さとう`
- 英語: `Smith`, `John`, `Mary`
- 韓国語: `김철수`, `이영희`
- 中国語: `王小明`, `李娜`
- その他の言語も対応

### 日付検出

以下の形式の日付を自動検出します（誕生日、有効期限、発行日など全ての日付）：

**西暦形式:**
- `2000年1月1日`、`2000年 1月 1日` (スペース入りも対応)
- `2000/1/1`
- `2000.1.1`
- `2000-1-1`
- `2000年1月` (年月のみ)

**和暦形式:**
- `令和5年1月1日`、`令和 5年 1月 1日` (スペース入りも対応)
- `令和5年1月`
- `令和5年`
- `R5.1.1` (略記)
- `R5/1/1` (略記)
- `平成元年`, `昭和64年` なども検出

**英語形式:**
- `27 Jun. 2023`, `27 June 2023` (日 月 年)
- `June 27, 2023`, `Jun 27 2023` (月 日, 年)
- `27-Jun-2023`, `27.Jun.2023` (区切り文字付き)
- `Jun. 27`, `June 27` (年なし)
- 月名は完全名と略称の両方に対応（大文字小文字を区別しない）

**スペース対応:**
- 半角・全角スペースが入っている日付も検出できます

### ごま塩ノイズ機能

モザイク処理を行う前に、検出された領域にごま塩ノイズを追加します。ごま塩ノイズとは、ランダムに白（塩）と黒（胡椒）のピクセルを配置するノイズで、モザイク処理と組み合わせることで、より強力に情報を隠蔽できます。

デフォルトでは、検出領域の5%のピクセルにノイズが追加されます。

### マージン機能

検出された領域（顔、名前、日付）に対して、デフォルトで15%のマージンを追加してモザイクをかけます。これにより、検出範囲の周辺も確実に隠すことができます。

## 注意事項

- **初回実行**: EasyOCRは初回実行時にモデルファイルをダウンロードするため、時間がかかります
- **処理速度**: OCR処理は比較的時間がかかります（画像1枚あたり数秒～十数秒）
- **検出精度**:
  - 顔検出の精度は画像の品質や角度に依存します
  - テキスト検出は文字の大きさ、フォント、背景によって精度が変わります
  - 日付検出は定型的なフォーマットに依存するため、特殊な表記は検出されない場合があります
  - OCRは日本語と英語に最適化されています
  - `OCR_CONFIDENCE_THRESHOLD` を調整することで、検出の精度と範囲のバランスを調整できます
    - 値を上げる（0.5～0.7）: 確実なテキストのみ検出（誤検出が減る）
    - 値を下げる（0.2～0.3）: より多くのテキストを検出（検出漏れが減る）
- **誤検出**:
  - 検出対象以外のテキスト（地名、商品名、一般的な単語など）も検出される可能性があります
  - 日付は誕生日、有効期限、発行日などを区別せず、全ての日付形式を検出します
  - `TARGET_NAMES` を設定することで、検出するテキストを限定し、誤検出を減らすことができます
- **マージン**: デフォルトで15%のマージンを追加するため、検出範囲より広い領域がモザイク処理されます

## 機能の個別設定

### OCRを無効にする

顔検出のみを使用したい場合は、`main.py` の設定を変更します：

```python
USE_OCR = False
```

### OCR精度を調整する

テキスト検出の精度を調整したい場合は、信頼度閾値を変更します：

```python
# より確実なテキストのみを検出（誤検出を減らす）
OCR_CONFIDENCE_THRESHOLD = 0.5  # または 0.6, 0.7

# より多くのテキストを検出（検出漏れを減らす）
OCR_CONFIDENCE_THRESHOLD = 0.3  # または 0.2
```

**推奨値:**
- **バランス重視**: 0.4（デフォルト）
- **精度重視**: 0.5～0.7（確実なものだけ検出）
- **網羅性重視**: 0.2～0.3（できるだけ多く検出）

### 日付検出のみを無効にする

名前検出は使用するが、日付検出は無効にしたい場合：

```python
DETECT_DATE = False
```

### ごま塩ノイズを無効にする

ごま塩ノイズを使用せず、モザイクのみで処理したい場合：

```python
ADD_SALT_PEPPER_NOISE = False
```

### ごま塩ノイズの密度を調整する

ノイズの密度を調整したい場合（0.0～1.0）：

```python
NOISE_AMOUNT = 0.10  # 10%のピクセルにノイズ（より強い）
NOISE_AMOUNT = 0.05  # 5%のピクセルにノイズ（デフォルト）
NOISE_AMOUNT = 0.02  # 2%のピクセルにノイズ（控えめ）
```

### マージンを調整する

マージンの大きさを調整したい場合（0.15 = 15%）：

```python
MOSAIC_MARGIN_RATIO = 0.20  # 20%のマージン
MOSAIC_MARGIN_RATIO = 0.10  # 10%のマージン
MOSAIC_MARGIN_RATIO = 0.0   # マージンなし
```

## どちらを使うべきか

### GUI版を推奨する場合
- 確実に必要な部分だけモザイクをかけたい
- 自動検出の結果を確認してから処理したい
- 手動で範囲を調整したい
- 少数の画像を処理する

### CLI版を推奨する場合
- 大量の画像を一括処理したい
- 自動検出の結果をそのまま使用して問題ない
- スクリプトやバッチ処理に組み込みたい
- 人手を介さず自動化したい
