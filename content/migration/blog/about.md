岐阜県出身。中学生の頃から地域のプログラミングスクールに通い、Scratch・VBA・電子工作で簡単なゲームやツールを作りながら、「自分で仕組みを作ることの面白さ」を感じ始めました。

商業高校の情報科では、簿記・会計を学びつつ、情報処理やプログラミングに多くの時間を使いました。授業や課題を通じて Web 制作やアプリ開発に触れ、**jQuery を使ったペアプログラミングでの Web ページ作成**、**C# の Windows アプリ（OpenCV の Haar Cascade を使った顔認識）**、**Swift のスマホアプリ（色当てゲーム）** など、身近な用途のプログラムを作る機会が増えました。さらに、**花札の画像認識 AI（YOLO の再学習）** の試作にも挑戦し、画像処理の基礎に触れました。

この頃には、コロナ禍で行われていた登校時の体温確認を効率化するため、**LINE 公式アカウント × Google Apps Script × Webhook** を組み合わせた体温確認システムも作りました。フォームの表示からスプレッドシートでの一覧管理までを自動化し、現場の負担を減らせました。

現在は高知の大学で情報系を学び、コンピュータサイエンスの基礎を体系的に固めています。大学では、次のような幅広い領域を学んでいます。

- **C 言語・Java・アセンブリ・MATLAB** を使ったプログラミング実験
- **ソフトウェア工学**に基づくウォーターフォール開発の実践
- **ネットワーク・データベース・Web 技術**の基礎

ソフトウェア工学演習では、架空のフリーマーケットアプリを題材に、要件定義から設計・実装・テストまでの一連の開発工程をチームで経験しました。リーダーを置かない方針の中で、**進捗の整理、ドキュメント方針の調整、環境構築のサポート**などを自然と引き受けながら、Next.js での実装にも関わりました。

個人開発では、授業で学んだことを**実用的な仕組みに落とし込むこと**を意識しています。大学入学後は Next.js・React・Astro などのモダンなフロントエンドを扱い、Python での自動化スクリプトやデータ処理も行っています。

代表的な制作物は、YouTube の視聴体験をよくするために作った [**Chrome 拡張機能「YouTube Watch Thumbnails」**](https://chromewebstore.google.com/detail/youtube-watch-thumbnails/aobeafpjgdgakpagffmlkfeognaiigci)（再生画面に常にサムネイルを表示）です。既存の拡張機能が使いづらかったので自作したもので、2025 年 11 月時点で**約 7,000 人が利用**し、YouTuber にも紹介してもらいました。

ほかにも、次のような小さなツールを作り続けています。

- Gmail から LINE・Discord への通知スクリプト
- 学習用の単語帳アプリへの一括登録ツール
- スクレイピングや文字起こしなどの作業を効率化するツール
- ISBN から書籍の情報を取得するツール

技術と並行して、資格の取得にも取り組んできました。**IT パスポート・情報セキュリティマネジメント・基本情報技術者・応用情報技術者**をはじめ、**日商 PC 検定・日商プログラミング検定・簿記・原価計算**、さらに**危険物取扱者 乙種 4 類・第二級陸上特殊無線技士・第二級海上特殊無線技士・第三級アマチュア無線技士**など、幅広い分野に挑戦しています。

現在は**データベーススペシャリスト試験**と**情報処理安全確保支援士試験**に向けて学習中です。

学生生活を振り返ると、「挑戦」と「実践」が中心でした。授業で学んだ知識をプロダクトに落とし込み、トラブルがあれば原因を調べて改善する。その繰り返しの中で、俯瞰的な視点とユーザー目線の大切さを強く実感しています。

趣味は Web アプリ制作、YouTube、吹奏楽、料理など。日常で気づいた「ちょっとした不便」を流さず、小さなツールとして形にすることを楽しんでいます。これからも、ゆるいペースで学習と制作を続けていくつもりです。

就活用に整理した内容なのでやたらと真面目に見えるかもしれませんが、基本は「作りたいから作る」ゆるい開発スタイルです。肩の力を抜いて試しながら進めているので、面白そうだと思ってもらえたらうれしいです。よろしくお願いします。
