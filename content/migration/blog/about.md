岐阜県を拠点に、会社員として働きながら、趣味で Web アプリや小さなツールを作っています。

## はじまり

中学生の頃に Scratch・VBA・電子工作に触れて、簡単なゲームやツールを作りながら「自分で仕組みを作ることの面白さ」を感じ始めました。

高校では情報処理やプログラミングに多くの時間を使い、Web 制作やアプリ開発に触れました。**jQuery を使ったペアプログラミングでの Web ページ作成**、**C# の Windows アプリ（OpenCV の Haar Cascade を使った顔認識）**、**Swift のスマホアプリ（色当てゲーム）** など、身近な用途のプログラムを作る機会が増えました。**花札の画像認識 AI（YOLO の再学習）** の試作にも挑戦し、画像処理の基礎に触れました。

**LINE 公式アカウント × Google Apps Script × Webhook** を組み合わせて、毎日の体温確認を自動化する仕組みを作ったこともあります。フォームの表示からスプレッドシートでの一覧管理までを自動化し、手作業の負担を減らせました。

## 大学で学んだこと

大学では情報系を専攻し、コンピュータサイエンスの基礎を体系的に学びました。

- **C 言語・Java・アセンブリ・MATLAB** を使ったプログラミング実験
- **ソフトウェア工学**に基づくウォーターフォール開発の実践
- **ネットワーク・データベース・Web 技術**の基礎

チーム開発の演習では、架空のフリーマーケットアプリを題材に、要件定義から設計・実装・テストまでを経験しました。**進捗の整理、ドキュメント方針の調整、環境構築のサポート**などを引き受けながら、Next.js での実装にも関わりました。

## 作ってきたもの

個人開発では、学んだことを**実用的な仕組みに落とし込むこと**を意識しています。Next.js・React・Astro などのフロントエンドを中心に、Python での自動化スクリプトやデータ処理も書いています。

代表的な制作物は、YouTube の視聴体験をよくするために作った [**Chrome 拡張機能「YouTube Watch Thumbnails」**](https://chromewebstore.google.com/detail/youtube-watch-thumbnails/aobeafpjgdgakpagffmlkfeognaiigci)（再生画面に常にサムネイルを表示）です。既存の拡張機能が使いづらかったので自作したもので、2025 年 11 月時点で**約 7,000 人が利用**し、YouTuber にも紹介してもらいました。

ほかにも、次のような小さなツールを作り続けています。

- Gmail から LINE・Discord への通知スクリプト
- 学習用の単語帳アプリへの一括登録ツール
- スクレイピングや文字起こしなどの作業を効率化するツール
- ISBN から書籍の情報を取得するツール

## いま

学生のあいだに学んだことを、いまは仕事と趣味の両方で使っています。知識を形にして、うまくいかなければ原因を調べて直す。その繰り返しの中で、全体を見渡す視点とユーザー目線の大切さを実感しています。

趣味は Web アプリ制作、YouTube、吹奏楽、料理など。日常で気づいた「ちょっとした不便」を流さず、小さなツールとして形にすることを楽しんでいます。

基本は「作りたいから作る」ゆるい開発スタイルです。肩の力を抜いて試しながら進めているので、面白そうだと思ってもらえたらうれしいです。よろしくお願いします。
