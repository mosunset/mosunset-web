Gmail に届いた大事なメールを、Google Apps Script（GAS）を使って LINE に自動で転送する仕組みを作りました。

> **注意**
> LINE Notify は 2025 年 3 月 31 日でサービスを終了しました。現在は通知の送り先を Discord の Webhook に切り替えて運用しています。

## なぜ作ったのか？

Gmail には毎日たくさんのメールが届きますが、特に大事なメールにはすぐ気づきたいものです。

- **EC サイトからの配送通知**
- **金融機関からの大事な連絡**
- **特定の相手からのメール**

こうした「見逃したくないメール」を、使い慣れた LINE や Discord で受け取れたら便利だと考えました。

## 仕組み

### Gmail の検索演算子で条件を決める

Gmail の検索演算子を使って、通知したいメールの条件を決めます。

```text
from:example@company.com subject:重要
```

### Google Apps Script で自動処理

GAS のトリガー機能で定期的に Gmail をチェックし、条件に合うメールが見つかったら、Discord の Webhook に送信します（以前は LINE Notify API を使っていました）。

### 通知先の変更（LINE Notify → Discord Webhook）

以前は LINE Notify を使って、簡単に LINE へメッセージを送っていました。サービス終了にともない、現在は Discord の Webhook で同じように即時通知しています。Discord の Webhook なら、チャンネルの設定から **Webhook の URL を発行するだけ**で、無料で通知を送れます。

## 主な機能

- **柔軟な条件設定**
  - 送信者・件名・本文など、さまざまな条件で絞り込める
- **通知の内容を変えられる**
  - 通知メッセージの中身を自由にカスタマイズできる
- **定期実行**
  - 決めた間隔（1 分〜1 時間ごと）で自動的にチェック
- **複数の条件に対応**
  - 条件ごとに別々の通知を設定できる

## 設定の流れ

1. **通知先の Webhook の URL を発行する**
   - Discord のサーバー・チャンネルの設定から Webhook の URL を作る
2. **Google Apps Script のプロジェクトを作る**
   - スクリプトエディタでコードを書く
   - 送り先として Discord の Webhook の URL を設定する
3. **トリガーを設定する**
   - 定期実行のスケジュールを決める
4. **テストする**
   - 正しく動くか確かめる

## メリット

- **完全無料**
  - GAS も Discord の Webhook も無料で使える
- **サーバー不要**
  - Google のインフラで動く
- **安定して動く**
  - Google のサービスなので止まりにくい
- **メンテナンスが簡単**
  - GAS の管理画面で設定を変えられる

## 注意点

- **実行回数の制限**
  - GAS には 1 日あたりの実行時間の上限がある
- **少し遅れる**
  - リアルタイムではなく、トリガーの間隔しだいで届く
- **Webhook の URL の管理**
  - URL を知っていれば誰でも投稿できるので、他人に見せない

## 使いどころ

- **仕事**：大事な取引先からのメール
- **個人**：EC サイトの配送状況
- **趣味**：イベント情報をすぐ確認
- **セキュリティ**：不審なログインの通知

メールの見逃しを防ぎ、大事な情報をすぐに受け取れる、便利な自動化ツールです。
